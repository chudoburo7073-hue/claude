# Когда я последний раз…

Трекер дел, у которых нет точного расписания: поменять зубную щётку, сменить постельное бельё, полить цветы, почистить чайник, позвонить родителям.

- Нажимаете «Сделал», и приложение запоминает дату.
- Интервал можно задать самому («раз в месяц») или оставить пустым: после двух отметок приложение посчитает ваш обычный ритм (медиана последних интервалов).
- Список сортируется по срочности: просрочено, скоро, по графику.
- У каждого дела есть персонаж, настроение которого зависит от статуса: спокоен, нервничает, паникует, спит или счастлив.
- Категории (дом, здоровье, растения, люди, техника) и фильтр по ним.
- «Отложить» на 1 день, 3 дня или неделю, если сейчас не до этого.
- Заметка к делу: модель фильтра, размер, где купить.
- В подробностях дела есть история, отметка задним числом, отмена последней отметки, изменение и удаление.

## Запуск

Откройте `index.html` в браузере. Данные хранятся в `localStorage` этого браузера.

Опубликованная версия (Artifact на claude.ai) хранит данные в вашем аккаунте, и они видны только вам.

## Структура

- `src/app.html` — исходник страницы (фрагмент, который публикуется как Artifact).
- `build.sh` — собирает из него самостоятельный `index.html`.
